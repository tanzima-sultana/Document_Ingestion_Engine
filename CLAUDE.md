## Code style

- Write verbose, explicit code. Prefer clarity over brevity or cleverness.
- Do not use list/dict/set comprehensions. Use explicit `for` loops with `.append()` or explicit assignment.
- Do not use `map()`, `filter()`, or `functools.reduce()`. Use explicit loops instead.
- Do not write single-line conditionals, single-line loops, or chained one-liners. One statement per line.
- Name functions and variables descriptively enough that control flow is readable without comments.
- Do not add a third-party dependency without asking the user first.
- Write explicit comments for each method. Write what input it takes, what output it produces and what it does in plain simple manner.
- Do not make any code change unless the user explicitly asks for it. While discussing or planning, only explain and give the plan.

## Environment setup

This project uses the `pyenv` virtualenv at `~/pyenv` (Python 3.10.12) for all Python version and dependency management. Do not use the system Python, and do not create a `venv`/`virtualenv` inside this repo. Never call `python`/`pip` against the system interpreter directly.

## Shell scripts

Any shell script added to this project (setup, run, test helpers) must follow the same pattern:
All commands below assume cuprrent working directory is the repo root (`DocIngestEngine/`).

1. Activate the environment:

```bash
   source ~/pyenv/bin/activate
```

2. Set `PYTHONPATH` relative to the repo root:

```bash
    export PYTHONPATH="$(pwd)/src"   # if invoked from repo root
    # if callable from elsewhere, resolve the repo root from the script's own location:
    REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"            # script at repo root (e.g. run.sh)
    export PYTHONPATH="$REPO_ROOT/src"
```
